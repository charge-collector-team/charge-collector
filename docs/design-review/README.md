- 브랜치: `codex/pleos-style-preview`
- 기준 main: `491117e25522bf6cf6e9566650886809ca342750`
- 변경 전: 해당 main에 포함된 `release/charge-collector-v0.1.apk` 실행 화면.
- 변경 후: 이 브랜치 소스로 빌드한 APK 실행 화면.
- 캡처일: 2026-11-15. **샘플 날짜는 2026-12-03**, 시연용 현위치는 공주 산성시장 공영주차타워. 실제 사용자 이동 기록이 아닙니다.
- 동일 Pleos 에뮬레이터 2560×1440에서 촬영. 차량 OS 창 재배치 후에는 실제 앱 창 좌표를 다시 읽어 절단했습니다. 아래 이미지는 OS 영역을 제외한 앱 부분 1680×1209이며, 내용·색·상태를 후처리하지 않았습니다.

## 변경 범위

| 유지 | 스타일 변경 |
|---|---|
| 기존 화면 배치·탭·스크롤·왼쪽 상세·지도 확대·트리 편집 | 밝은 중립색 바탕/카드와 검은 메달 진열면 |
| 충전·보상·합성·동 전용 교환·주행 제한 로직 | 파란 조명과 버튼 그라데이션을 단색 조작부로 변경 |
| 기존 메달 원본 그림·공식 캐릭터·트리 장면 | 금·한정 메달의 외부 발광 제거, 진열 프레임과 수량 표시 단순화 |
| 기기 Asta Sans / 숫자 Bai Jamjuree | Material3의 모든 텍스트 역할에 기존 Asta Sans 지정 |
| 기존 선택/진입 동작과 상태 | 선택선을 사각 카드에서 메달의 몸체·고리 외곽으로 변경 |

팔레트: 바탕 `#F7F8FA`, 카드 `#FFFFFF`, 본문 `#1D1E21`, 보조 `#686A72`, 조작부 `#44464E`, 진열면 `#151618`.
서체 기준: [Pleos Typography](https://document.pleos.ai/en/docs/connect/guide/docs-design/foundations/typography). 기존 기기 폰트 파일과 시스템 대체 동작을 유지합니다.

Figma v31의 새 화면 구성은 이식하지 않았습니다. **현재 main에 없는 독립 지도·설정 화면과 새 메뉴를 추가하지 않았습니다.** 1주년 날짜·운영 정책도 이번 스타일 작업에서 바꾸지 않았습니다.

## 검증과 검토

메달 상세를 닫으면 기존 지역 진열로 복귀하는 것도 확인했습니다. [닫은 뒤 실제 화면](after-detail-closed.png). 충전 정보 면의 글자 대비는 실행 검수 후 보완해 재촬영했습니다.

- 기존 `:core:test` **32개 통과**, 실패/오류 0. 핵심 엔진·충전 서비스·앱 데이터 파일·메달 자산의 Git diff 없음.
- `:app:assembleRelease` 및 `lintVitalRelease` 통과. 화면 이미지는 실제 에뮬레이터 실행본에서 촬영했습니다.
- 전후 이미지에서 배치 유지, 글자 대비, 활성/비활성, 선택선, 패널, 지도/트리 내용을 확인합니다. 실차·교환 서버·실제 충전 판정의 검증 자료는 아닙니다.
- 주행 제한 분기와 콜백은 유지했습니다. 이번 환경에서 차량 시험 콘솔의 gear bridge가 준비되지 않아 **주행 제한 화면의 전후 캡처는 미확보**입니다. 제한을 해제하거나 가짜 동작을 넣지 않았습니다. 머지 검토 시 기존 차량 시험 환경에서 추가 확인할 항목입니다.

수정 소스: `MainActivity.kt`, `Screens.kt`, `Images.kt` 3개. 문서와 캡처 외 파일은 추가하지 않았습니다. 기존 `release/charge-collector-v0.1.apk`는 원본 그대로라 **수정본 실행에는 아래 명령으로 새로 빌드**해야 합니다.

```bash
./gradlew :core:test :app:assembleRelease
adb -e install -r app/build/outputs/apk/release/app-release.apk
adb -e shell am start --user 10 -n kr.chargebadge/.MainActivity --es sample 2026-12-03 --es here 36.45881,127.12272
```
